# Software Sostenible ONG

Sitio web de una ONG ficticia sobre software libre, accesibilidad y sostenibilidad digital. Lo desarrollamos como práctica de **Diseño de Interfaces Web en 2.º de DAW**.

La web incluye una página de inicio, un listado de artículos, una página de detalle, un formulario de donación y una página de contacto.

## Qué hemos trabajado

- Maquetación adaptable con HTML y CSS y un modo de alto contraste.
- Optimización de imágenes en WebP, con JPEG de respaldo en dos tarjetas y tres tamaños para la portada.
- Logotipos e iconos en SVG, con los créditos de las imágenes externas en el pie de página cuando su licencia lo requiere.

## Cómo verlo

Descarga o clona el repositorio y abre `index.html` en tu navegador. También puedes abrir el proyecto con Live Server en Visual Studio Code.
